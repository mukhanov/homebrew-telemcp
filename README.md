# telemcp Homebrew Tap

Install [telemcp](https://github.com/mukhanov/telemcp) — a local Telegram
archive with a resident live-sync daemon and a read-only
[MCP](https://modelcontextprotocol.io) server — via Homebrew:

```sh
brew install mukhanov/telemcp/telemcp
```

Requires Telegram Desktop installed and logged in at least once; the sync
authorizes through its local session (`tdata`). See the
[main repository](https://github.com/mukhanov/telemcp) for setup and usage.
